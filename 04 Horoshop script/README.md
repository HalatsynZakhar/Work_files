# Инструкция: Выгрузка цен из Docker (Changedetection.io) в Хорошоп

## Назначение
Скрипт **`Horoshop_docker_processing.py`** автоматизирует сбор цен и статусов наличия товаров напрямую из работающего контейнера Docker с проектом **Changedetection.io**, сопоставляет их с вашим файлом артикулов `articles.xlsm` и формирует готовые отчеты для Хорошоп и руководства.

> **Главное отличие от старого скрипта (`Horoshop processing.py`):**
> Больше **не нужно** открывать браузер, применять фильтр и вручную сохранять страницу в файл `tracker_page.html`. Скрипт сам обращается в Docker и за 1 секунду считывает актуальные данные по всем товарам.

## Пошаговый процесс работы

После запуска скрипта в консоли:

1. **Поиск контейнера:** Скрипт автоматически находит активный контейнер `changedetectionio-changedetection-1` и извлекает актуальную базу цен.
2. **Выбор магазина-партнера (или бренда):**
   Отобразится нумерованный список:
   - `0` — Все магазины без фильтрации.
   - `1` — **Будинок іграшок** (установлен **по умолчанию**).
   - Другие магазины: *Чудо Острів, Розетка, Епіцентр, Fotos, Comfy, Brain, Антошка* и др.
   
   > 💡 **Подсказка:** Если нужен «Будинок іграшок» — просто нажмите клавишу **`Enter`**.

3. **Выбор колонки с артикулами:**
   Скрипт откроет `articles.xlsm` и покажет колонки:
   - `0 : Артикул`
   - `1 : ХОРОШОП АРТИКУЛ`
   
   > 💡 **Подсказка:** Просто нажмите клавишу **`Enter`** (по умолчанию выберется колонка `Артикул`).

4. **Формирование файлов отчета:**
   Скрипт сопоставит товары и сохранит файлы в папке отчетов:
   - `ИТОГОВЫЙ_ОТЧЕТ.xlsx`
   - `ПОЛНАЯ_ТАБЛИЦА_МОНИТОРИНГА.xlsx`

---

## Структура сформированных файлов

### 1. Файл `ИТОГОВЫЙ_ОТЧЕТ.xlsx`:
- **Лист 1: `Готово к импорту`**
  - Только подтвержденные товары в наличии (`+`) с ценой.
  - Колонки: `Артикул`, `ХОРОШОП АРТИКУЛ`, `Цена` (без лишних полей, сразу готово для импорта в Хорошоп).
- **Лист 2: `Полный отчет`**
  - Все ваши артикулы.
  - Колонки: `Артикул`, `ХОРОШОП АРТИКУЛ`, `Цена`, `Найдено у партнера` (`+`), `Наличие у партнера` (`+` / `-`).
- **Лист 3: `Полная информация`**
  - Детальное сопоставление со всеми подробностями:
    `Артикул`, `ХОРОШОП АРТИКУЛ`, `Цена`, `Валюта`, `Наличие у партнера`, `Название у партнера`, `Магазин`, `Бренд`, `Ссылка на товар`, `Дата проверки`.
- **Лист 4: `База трекера (все товары)`**
  - Все 780+ товаров из Docker с ценами, ссылками, магазинами и наличием.

### 2. Файл `ПОЛНАЯ_ТАБЛИЦА_МОНИТОРИНГА.xlsx`:
Отдельный файл для аналитики и руководства:
- **Лист 1: `Детальное сопоставление`** — ваши артикулы со всеми ссылками, ценами и статусами.
- **Лист 2: `Вся база трекера Docker`** — полный срез базы мониторинга.
- **Лист 3: `Готово к импорту`** — срез цен для импорта.

## Алгоритм сопоставления артикулов

Скрипт использует 3-этапный умный поиск:
1. **По артикулу в ссылке:** для сайтов вроде `bi.ua` (`.../mashinka-20155.html` -> `20155`).
2. **По артикулу в названии товара:** если артикул указан в заголовке трекера (например, `S107H RED Розетка`, `TG1009 Blue Будинок Іграшок`, `X15A White Brain`). Это решает проблему товаров, у которых в ссылке нет артикула или присутствуют дополнительные суффиксы.
3. **По подстроке в URL:** как резервный поиск для нестандартных ссылок.

## Что делать, если Docker не запущен?

Если при запуске появляется сообщение, что контейнер не найден:
1. Убедитесь, что запущен **Docker Desktop**.
2. Откройте командную строку или PowerShell и выполните:
   ```cmd
   cd C:\projects\changedetection.io
   docker-compose up -d
   ```
   Либо запустите батник `Обновление трекер цен.bat` на Рабочем столе.
